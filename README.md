# Alen Paunov — Portfolio

Personal portfolio of **Alen Paunov** — AI Integration Strategist & Educational Expert.

- **Live:** deployed on GitHub Pages
- **Stack:** static HTML/CSS/JS, GSAP + ScrollTrigger, Three.js (CDN, no build step)
- **Pages:**
  - `index.html` — main landing page (EN/BG, dark neon design, WebGL hero)
  - `index-gallery.html` — immersive spherical gallery of media appearances

## Local development

Any static server works:

```bash
npx serve .
```

## Deploy

Pushed to `main` → GitHub Pages serves the repo root. No build required.
